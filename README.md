# 🚀 프로젝트명: 실시간 스마트 환경 관리 시스템

온도와 습도를 실시간으로 측정하고,  
환경 상태에 따라 LED, 버저, 모터가 반응하는 **스마트 환경 관리 시스템**입니다.

---

## 🎯 프로젝트 목표

이 프로젝트는 온습도 센서를 이용해 주변의 **온도와 습도**를 실시간으로 측정합니다.

측정한 값에 따라 RGB LED 색상이 바뀌고,  
습도가 너무 낮거나 높으면 버저가 울립니다.

또한 온도가 너무 높을 경우에는 DC모터가 자동으로 돌아가  
작은 선풍기처럼 온도를 식히는 역할을 합니다.

---

## 🛠️ 주요 기능

### ✅ 필수 기능

- 🌡️ 온습도 센서를 이용한 실시간 데이터 측정
- 💡 온도와 습도 상태에 따른 RGB LED 색상 변화
  - 낮음 → 파란색 LED 🔵
  - 적정 → 초록색 LED 🟢
  - 높음 → 빨간색 LED 🔴
- 🔊 습도가 너무 낮거나 높으면 버저 울리기
- 🌀 온도가 너무 높으면 DC모터가 돌아가 선풍기 역할하기

## 💡 제작 동기

일상생활을 하다 보면 집 안이 너무 건조해질 때가 있습니다.  
저는 건조할 때 코피가 나는 경우가 있어서 습도를 미리 확인할 수 있으면 좋겠다고 생각했습니다.

또 여름에 비가 오면 날씨가 덥고 습해져서 불편할 때가 많습니다.  
그래서 온도와 습도를 미리 확인하고,  
LED와 버저, 모터를 이용해 현재 환경 상태를 알려주는 장치를 만들고 싶었습니다.

이런 이유로 **실시간 스마트 환경 관리 시스템**을 제작하게 되었습니다.

## ⚙️ 작동 원리

1. 🌡️ 온습도 센서가 주변의 온도와 습도를 측정합니다.
2. 📊 아두이노가 측정된 값을 읽고 상태를 판단합니다.
3. 💡 온도와 습도 상태에 따라 RGB LED 색상이 바뀝니다.
4. 🔊 습도가 너무 낮거나 높으면 버저가 울립니다.
5. 🌀 온도가 너무 높으면 DC모터가 돌아가 선풍기처럼 작동합니다.

---

## 🌈 LED 색상 기준

| 상태 | LED 색상 | 의미 |
|---|---|---|
| 낮음 | 🔵 파란색 | 온도나 습도가 낮음 |
| 적정 | 🟢 초록색 | 생활하기 좋은 상태 |
| 높음 | 🔴 빨간색 | 온도나 습도가 높음 |

---

## 🔊 버저 작동 기준

습도가 너무 낮거나 너무 높을 경우 버저가 울립니다.

- 습도가 너무 낮음 → 건조한 상태
- 습도가 너무 높음 → 습한 상태

버저를 통해 현재 환경이 좋지 않다는 것을 쉽게 알 수 있습니다.

---

## 🌀 모터 작동 기준

온도가 너무 높을 경우 DC모터가 자동으로 돌아갑니다.  
DC모터는 작은 선풍기처럼 작동하여 온도를 낮추는 역할을 합니다.
